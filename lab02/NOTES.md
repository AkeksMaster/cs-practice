\# Lab 02



\## Рабочая папка



Рабочая папка — это файлы проекта, которые находятся у меня на компьютере и с которыми я сейчас работаю.



\## Индекс



Индекс — это область, куда я добавляю изменения, которые хочу включить в следующий коммит.



\## Коммит



Коммит — это сохранённая версия подготовленных изменений с описанием того, что было изменено.



\## Git и GitHub



Git — это система контроля версий, которая позволяет отслеживать изменения в файлах и хранить историю проекта.



GitHub — это интернет-сервис для хранения Git-репозиториев и совместной работы с ними.



Git работает с репозиторием на компьютере, а GitHub позволяет хранить репозиторий удалённо и обмениваться им с другими людьми.
