\# Lab 02



\## Рабочая папка



Рабочая папка — это файлы проекта, которые находятся у меня на компьютере и с которыми я сейчас работаю.



\## Индекс



Индекс — это область, куда я добавляю изменения, которые хочу включить в следующий коммит.



\## Коммит



Коммит — это сохранённая версия подготовленных изменений с описанием того, что было изменено.



\## Git и GitHub



Git — это система контроля версий, которая позволяет отслеживать изменения в файлах и хранить историю проекта.



GitHub — это интернет-сервис для хранения Git-репозиториев и совместной работы с ними.



Git работает с репозиторием на компьютере, а GitHub позволяет хранить репозиторий удалённо и обмениваться им с другими людьми.



\## Использованные команды



\### git status



Показывает состояние рабочей папки и индекса: какие файлы изменены, какие подготовлены к коммиту, а какие ещё не отслеживаются.



\### git diff



Показывает изменения между рабочей папкой и индексом.



\### git diff --staged



Показывает изменения, которые уже добавлены в индекс и попадут в следующий коммит.



\## Ветки



Ветка — это отдельная линия разработки, которая позволяет работать с изменениями независимо от другой ветки.



При создании нового коммита ветка перемещается вперёд и начинает указывать на новый коммит.



Слияние объединяет изменения одной ветки с другой. В данном задании ветка explain-branches будет объединена с main.
